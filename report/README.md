Коли почав тестувати кнопку на дрябежіння зміг його отримати тільки при маленькому ударі по краю кнопки

Питання:
Також якщо не реалізовувати softeare debounce при інтенсивному брязкоті відбувається краш через томущо час виконання приривання занадто великий і спрацьовує WDT.
Було б круто якби ви пояснили більш детально про те як працює WDT, і чому велика кількість приривань одномоментно викликає краш. Що можна виконувати в пририванні, а що не можна.
Як я вже дізнався то неможна використовувати Serial томущо це операція занадто важка, займає доволі багато часу, також delay не можна використовувати.
